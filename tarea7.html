Resumen de HTML: Principales conceptos y etiquetas

Esta pagina va a resumir los principales conceptos y etiquetas vistas en la clase de programación web 1, en el modulo HTML

Conceptos principales HTML

HTML

El lenguaje marcado de hipertexto (HTML) es un lenguaje de marcas que se utiliza para estructurar sitios web

Elemento HTML

Un elemento HTML es la unidad básica de contenido y estructura en una página web, y esta compuesta de:

  1. Una etiqueta de apertura
  2. Los atributos y valor
  3. El contenido del elemento
  4. Una etiqueta de cierre

Etiqueta <HEAD>

Una etiqueta que se utilza para comnicarse con el navegadro a través de metadatos, permite mejorar el SEO, además enlazan archivos externos de estilos o scripts

Etiqueta <BODY>

Una etiqueta que contiene todo el contenido visible de la página web

Contenedores semanticos

<Header> Etiqueta utilizada para el contenido introductorio d euna pagina web, puede contener el logo,menu de navegacion principal, nombre de la empresa,etc...
<Nav> Etiqueta utilizada para el menu de navegacion principal, suele contener enlaces a otras paginas relacionadas o navegar por la pagina principal no debe haber más de una en la pagina
<Main> Etiqueta unica de una pagina web cuyo proposito es resaltar nuestro objetivo o mensaje principal del sitio web,dentro se colocara el contenido principal de nuestra pagina
<Section> Es una etiqueta que poco a poco se intenta que sustiruya a <div>, su uso es para dividir a una pagina web en secciones y agrupar contenido relacionado
<Article> Etiqueta que se utiliza para agrupar contenido autonomo, que si se separa de otro contenido sigue teniendo cooerencia, normalmemnte se compone de un encabezado y contenido
<Footer> Etiqueta que se encunetra al final de una pagina y funciona como cierre del sitio web, a menudo contiene datos de contacto, derechos de autor u otra información complementaria
<Aside> Etiqueta que representa una seccion de la pagina web cuyo contenido no esta directamente relacionado con el contenido principal del documento, como:barras laterales, publicidad, enlaces a otros articulos relacionados, etc...

Elementos principales de HTML

Elemento <a>

Este elemento contiene enlaces para navegar a otras páginas:

  • Externos
  • Internos
  • Anclaje

Algunos valores especiales que tiene en su atributo "href" son:

href="https://wa.me/1524524525"
Este valor envia un wsp a un numero especifico
href="mailto:example@gmail.com"
Este valor envia un mail a un correo especifico

Elemento <form>

Es la manera en la que los usuarios se pueden comunicar con una página web, gracias a este elemento se puede procesar datos de los usuarios segun el objetivo de nuestra pagina
