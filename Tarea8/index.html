Tipos de estilos en css

Estilos en linea

Estos estilos se van a agregar directamente en el eleemnto html mediante el atributo style

Este parrafo tiene estilos en linea

Estilos internos

Estos estilos se agregan en el mismo archivo html, dentro de la etiqueta <head> y para agregarlos se utiliza el elemento:<style>

Estilos externos

Estos estilos son los que se recomiendan utilizar, ya que ofrecen modularidad, facil mantenimiento,orden, eficiencia, entre otras ventajas, para agregar una hoja de estilos externa, dentro de la etiqueta <head> se utilza el elemnto <link>, donde se especifica la ruta de nuestra hoja de estilos.
